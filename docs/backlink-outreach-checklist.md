# Backlink outreach checklist

Purpose: aitoolduel.com is indexed and getting impressions, but ranks too low
(avg. position ~40-50) to get clicks. Backlinks and real referral traffic are
what move that number — this file tracks the outreach needed to get them.

**How to use this:** work through the sections below, mark each row done with
the date once submitted/posted, and add notes on what happened (accepted,
rejected, no response, got traffic). Update this file as you go so nothing
gets duplicated or forgotten.

**Timing rule:** don't post to more than one subreddit per day with a link —
same-day cross-posting is the single biggest trigger for Reddit's spam
filter. Directories have no such restriction; submit those whenever.

---

## Reusable descriptions

Use whichever length fits the platform's character limit.

**One-liner (≤60 chars):**
> Honest, side-by-side AI tool comparisons — no fluff.

**Short (≤160 chars):**
> AI Tool Duel compares ChatGPT, Claude, Gemini, Midjourney, and 40+ other AI tools side-by-side, with real pros/cons and community voting on every matchup.

**Long (elevator pitch, ~2-3 sentences):**
> AI Tool Duel is a free comparison site for AI tools — head-to-head breakdowns of pricing, features, and honest verdicts for tools like ChatGPT vs Claude, Midjourney vs DALL-E, and Cursor vs GitHub Copilot. It also includes a free AI text detector, a prompt generator, and a quiz to help you pick the right tool. Built to cut through marketing claims with straight comparisons and real community votes on each matchup.

## Reddit posts (draft — different angle per subreddit, don't post same-day)

### r/SideProject
**Angle:** builder story, not a product pitch.

> **Title:** Built a site that compares AI tools head-to-head instead of just listing them
>
> Got tired of "best AI tools of 2026" listicles that are just ranked ads, so I built a comparison site that puts two tools side by side — pricing, actual pros/cons, and lets people vote on which one they'd actually pick. Currently covers 40+ matchups (ChatGPT vs Claude, Midjourney vs DALL-E, Cursor vs Copilot, etc.) plus a free AI text detector and prompt generator.
>
> Would love feedback on which comparisons are missing or which ones feel off. [link in first comment, not the post body]

### r/artificial
**Angle:** discussion-starter, site mentioned as context not the point.

> **Title:** Anyone else find "best AI tool" articles useless because they never actually compare anything?
>
> Most "top 10 AI tools" content is just a ranked list with affiliate links, no real comparison of what's actually different between them. I ended up building my own side-by-side comparison tool to answer this for myself — curious if others have found better resources for genuinely comparing AI tools rather than just ranking them.

### r/Entrepreneur (or r/SaaS)
**Angle:** lessons-learned framing, useful even to people who never click through.

> **Title:** 3 months into a solo AI-tools comparison site — indexed fine, basically zero clicks. Here's what I learned.
>
> Site's been live for a few months, Google's indexed everything (thousands of impressions), but average ranking position is stuck around page 4-5 so almost nobody clicks through. Turns out indexing was never the bottleneck — it's domain authority, which apparently only comes from real backlinks and time. Sharing in case it saves someone else the same detour.
